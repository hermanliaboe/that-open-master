Array/object spreading:
const objA = {key1: "Value 1", key2: "Value2"}
const objB = {key3: "Value 3", key4: "Value4"}

const objC = {...objA} #copies the values of A into C
const objC = {...objA, ...objB} # key1: "Value 1", key2: "Value2", key3: "Value 3", key4: "Value4"

Promises
JavaScript doesnt wait for each line to finish
let's say you have a const userData = getUserdata(). it uses a function that takes time to execute. the next lines will execute while waiting on this.
if you want the value before moving on, you need to write like this:
const userData = await getUserData()
you can only use await if the JavaScript file is set as a module. check this in the index.html
if you want to use await inside a function, the funtion needs to be of type async
this is called asyncronised programming or something
async function getUserJob() {
  const userData = await getUserData()
  const { job } = userData
  return job
}
